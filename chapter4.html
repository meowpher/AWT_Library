Introduction to Object-Oriented Programming

Object-Oriented Programming (OOP) is a programming paradigm that organizes code around objects and classes. Unlike procedural programming which focuses on procedures or functions, OOP focuses on creating objects that contain both data and functions.

Benefits of OOP:

  • • Modularity: Code is organized into reusable objects
  • • Reusability: Objects can be reused across different programs
  • • Maintainability: Easier to update and debug code
  • • Scalability: Better structure for large applications
  • • Encapsulation: Data is protected from external interference
  • • Inheritance: Create new classes based on existing ones

OOP vs Procedural Programming:

Procedural Programming
  • • Focus on procedures/functions
  • • Data and functions are separate
  • • Top-down approach
  • • Less code reusability
Object-Oriented Programming
  • • Focus on objects and classes
  • • Data and functions are bundled
  • • Bottom-up approach
  • • High code reusability

Core OOP Concepts

Class

A blueprint or template for creating objects. Defines properties and methods.

Object

An instance of a class. Contains actual data values and can call methods.

Inheritance

Creating new classes based on existing classes, inheriting their properties and methods.

Polymorphism

Same method name can perform different tasks based on the object context.

Encapsulation

Bundling data and methods into a single unit and controlling access to them.

Abstraction

Hiding complex implementation details and showing only essential features.

Classes in PHP

A class is a user-defined data type that consists of data members (properties) and member functions (methods). Classes are defined using the class keyword.

Basic Class Definition
<?php
// Basic class definition
class Book {
    // Properties (data members)
    public $title;
    public $author;
    public $price;
    public $isbn;
    
    // Methods (member functions)
    public function displayInfo() {
        echo "Title: " . $this->title . "\n";
        echo "Author: " . $this->author . "\n";
        echo "Price: $" . $this->price . "\n";
        echo "ISBN: " . $this->isbn . "\n";
    }
    
    public function applyDiscount($discountPercent) {
        $discountAmount = $this->price * ($discountPercent / 100);
        $this->price -= $discountAmount;
        return $this->price;
    }
    
    public function getTitle() {
        return $this->title;
    }
    
    public function setTitle($title) {
        $this->title = $title;
    }
}

// Class with constructor
class Student {
    public $name;
    public $age;
    public $grade;
    public $courses = [];
    
    // Constructor
    public function __construct($name, $age, $grade) {
        $this->name = $name;
        $this->age = $age;
        $this->grade = $grade;
        echo "Student object created for $name\n";
    }
    
    // Destructor
    public function __destruct() {
        echo "Student object destroyed for $this->name\n";
    }
    
    public function enrollCourse($course) {
        $this->courses[] = $course;
        echo "$this->name enrolled in $course\n";
    }
    
    public function displayInfo() {
        echo "Student Information:\n";
        echo "Name: $this->name\n";
        echo "Age: $this->age\n";
        echo "Grade: $this->grade\n";
        echo "Courses: " . implode(", ", $this->courses) . "\n";
    }
    
    public function calculateAverage($scores) {
        return array_sum($scores) / count($scores);
    }
}

// Class with private properties
class BankAccount {
    private $accountNumber;
    private $balance;
    private $accountHolder;
    
    public function __construct($accountNumber, $accountHolder, $initialBalance = 0) {
        $this->accountNumber = $accountNumber;
        $this->accountHolder = $accountHolder;
        $this->balance = $initialBalance;
    }
    
    public function deposit($amount) {
        if ($amount > 0) {
            $this->balance += $amount;
            echo "Deposited: $$amount\n";
            return true;
        }
        return false;
    }
    
    public function withdraw($amount) {
        if ($amount > 0 && $amount <= $this->balance) {
            $this->balance -= $amount;
            echo "Withdrawn: $$amount\n";
            return true;
        }
        return false;
    }
    
    public function getBalance() {
        return $this->balance;
    }
    
    public function getAccountInfo() {
        return [
            "accountNumber" => $this->accountNumber,
            "accountHolder" => $this->accountHolder,
            "balance" => $this->balance
        ];
    }
}
?>

Class Components:

  • • Properties: Variables that hold object data
  • • Methods: Functions that define object behavior
  • • Constructor: Special method called when object is created
  • • Destructor: Special method called when object is destroyed
  • • $this: Keyword to refer to current object

Objects in PHP

Objects are instances of classes. They are created using the new keyword and contain actual data values. Each object has its own set of properties and can call the methods defined in its class.

Creating and Using Objects
<?php
// Creating objects from classes
$book1 = new Book();
$book2 = new Book();

// Setting object properties
$book1->title = "PHP Programming";
$book1->author = "John Smith";
$book1->price = 49.99;
$book1->isbn = "978-0123456789";

$book2->title = "Web Development";
$book2->author = "Jane Doe";
$book2->price = 39.99;
$book2->isbn = "978-9876543210";

// Calling object methods
echo "Book 1 Information:\n";
$book1->displayInfo();

echo "\nBook 2 Information:\n";
$book2->displayInfo();

// Applying discount
echo "\nApplying 10% discount to Book 1:\n";
$newPrice = $book1->applyDiscount(10);
echo "New price: $$newPrice\n";

// Creating Student objects
$student1 = new Student("Alice Brown", 18, "A");
$student2 = new Student("Charlie Davis", 19, "B");

// Using object methods
$student1->enrollCourse("Mathematics");
$student1->enrollCourse("Physics");
$student1->enrollCourse("Chemistry");

echo "\n";
$student2->enrollCourse("English");
$student2->enrollCourse("History");

// Display student information
echo "\n";
$student1->displayInfo();

echo "\n";
$student2->displayInfo();

// Calculate average score
$scores1 = [85, 92, 78, 88, 90];
$average1 = $student1->calculateAverage($scores1);
echo "\nAlice's average score: " . number_format($average1, 2) . "\n";

// Using BankAccount class
$account1 = new BankAccount("ACC001", "John Doe", 1000);
$account2 = new BankAccount("ACC002", "Jane Smith", 500);

echo "\nBanking Operations:\n";
echo "==================\n";

$account1->deposit(200);
$account1->withdraw(100);
echo "Account 1 balance: $" . $account1->getBalance() . "\n";

$account2->deposit(300);
echo "Account 2 balance: $" . $account2->getBalance() . "\n";

// Multiple objects of same class
echo "\nCreating multiple Book objects:\n";
$books = [];
$bookData = [
    ["PHP Basics", "Mike Johnson", 29.99],
    ["Advanced PHP", "Sarah Wilson", 59.99],
    ["PHP Frameworks", "David Lee", 45.99]
];

foreach($bookData as $data) {
    $book = new Book();
    $book->title = $data[0];
    $book->author = $data[1];
    $book->price = $data[2];
    $books[] = $book;
}

// Display all books
foreach($books as $index => $book) {
    echo "\nBook " . ($index + 1) . ":\n";
    $book->displayInfo();
}

// Object comparison
if ($book1 === $book2) {
    echo "\nBoth variables refer to the same object";
} else {
    echo "\nBoth variables refer to different objects";
}

// Cloning objects
$book3 = clone $book1;
$book3->title = "Cloned Book";
echo "\nOriginal book title: " . $book1->title . "\n";
echo "Cloned book title: " . $book3->title . "\n";
?>

Access Modifiers

Access modifiers control the visibility and accessibility of class properties and methods. PHP provides three access modifiers: public, private, and protected.

Modifier Description Access From
public Accessible from anywhere Class, Child Classes, Outside
private Only accessible within the same class Only within the class
protected Accessible within class and child classes Class and Child Classes
Access Modifiers Examples
<?php
// Class demonstrating access modifiers
class Employee {
    // Public properties - accessible everywhere
    public $name;
    public $department;
    
    // Private properties - only accessible within this class
    private $salary;
    private $employeeId;
    
    // Protected properties - accessible in this class and child classes
    protected $joinDate;
    protected $performanceRating;
    
    public function __construct($name, $department, $salary, $employeeId) {
        $this->name = $name;
        $this->department = $department;
        $this->salary = $salary;
        $this->employeeId = $employeeId;
        $this->joinDate = date("Y-m-d");
        $this->performanceRating = "Good";
    }
    
    // Public method - accessible everywhere
    public function getBasicInfo() {
        return "Name: $this->name, Department: $this->department";
    }
    
    // Private method - only accessible within this class
    private function calculateBonus() {
        return $this->salary * 0.1; // 10% bonus
    }
    
    // Protected method - accessible in this class and child classes
    protected function getPerformanceSummary() {
        return "Performance: $this->performanceRating, Join Date: $this->joinDate";
    }
    
    // Public method that uses private method
    public function getSalaryWithBonus() {
        $bonus = $this->calculateBonus();
        return $this->salary + $bonus;
    }
    
    // Public method that uses protected method
    public function getFullInfo() {
        $basicInfo = $this->getBasicInfo();
        $performance = $this->getPerformanceSummary();
        return "$basicInfo, $performance";
    }
    
    // Getter for private property
    public function getSalary() {
        return $this->salary;
    }
    
    // Setter for private property
    public function setSalary($salary) {
        if ($salary > 0) {
            $this->salary = $salary;
        }
    }
}

// Child class to demonstrate inheritance and access
class Manager extends Employee {
    private $teamSize;
    
    public function __construct($name, $department, $salary, $employeeId, $teamSize) {
        parent::__construct($name, $department, $salary, $employeeId);
        $this->teamSize = $teamSize;
    }
    
    // Child class can access protected members
    public function getTeamInfo() {
        $performance = $this->getPerformanceSummary(); // Protected method from parent
        return "Manager: $this->name, Team Size: $this->teamSize, $performance";
    }
    
    // Cannot access private members of parent class
    // This would cause an error:
    // public function getManagerSalary() {
    //     return $this->salary; // Error - private property
    // }
}

// Demonstration
echo "=== ACCESS MODIFIERS DEMONSTRATION ===\n\n";

// Create employee object
$emp1 = new Employee("John Doe", "IT", 50000, "EMP001");

// Access public properties
echo "Public Property Access:\n";
echo "Name: " . $emp1->name . "\n";        // Works - public
echo "Department: " . $emp1->department . "\n"; // Works - public

// Access private properties - ERROR
// echo "Salary: " . $emp1->salary . "\n";    // Error - private
// echo "Employee ID: " . $emp1->employeeId . "\n"; // Error - private

// Access protected properties - ERROR
// echo "Join Date: " . $emp1->joinDate . "\n"; // Error - protected

// Use getter method for private property
echo "\nUsing Getter Methods:\n";
echo "Salary: $" . $emp1->getSalary() . "\n"; // Works - public method

// Call public methods
echo "\nPublic Method Access:\n";
echo $emp1->getBasicInfo() . "\n";          // Works - public method
echo $emp1->getSalaryWithBonus() . "\n";     // Works - public method

// Call private method - ERROR
// $emp1->calculateBonus(); // Error - private method

// Call protected method - ERROR
// $emp1->getPerformanceSummary(); // Error - protected method

// Create manager object (child class)
echo "\n=== CHILD CLASS ACCESS ===\n\n";
$mgr1 = new Manager("Jane Smith", "HR", 70000, "MGR001", 5);

// Child class can access inherited public properties
echo "Manager Name: " . $mgr1->name . "\n";

// Child class can access protected methods from parent
echo $mgr1->getTeamInfo() . "\n";

// Child class cannot access private properties from parent
// echo "Manager Salary: " . $mgr1->salary . "\n"; // Error

// Demonstrate encapsulation benefits
echo "\n=== ENCAPSULATION BENEFITS ===\n\n";

// Direct modification of public property
$emp1->name = "John Modified"; // Works but not recommended
echo "Modified Name: " . $emp1->name . "\n";

// Proper way to modify using setter
$emp1->setSalary(55000);
echo "Updated Salary: $" . $emp1->getSalary() . "\n";

// Validation in setter prevents invalid data
$emp1->setSalary(-1000); // Won't work due to validation
echo "Salary after invalid attempt: $" . $emp1->getSalary() . "\n";
?>

Best Practices for Access Modifiers:

  • • Use private for internal implementation details
  • • Use protected for properties/methods meant for inheritance
  • • Use public for the class interface (API)
  • • Always use getter/setter methods for private properties
  • • Validate data in setter methods

Inheritance

Inheritance is a mechanism where a new class (child class) is created based on an existing class (parent class). The child class inherits properties and methods from the parent class and can add its own specific features.

Inheritance Examples
<?php
// Parent class
class Vehicle {
    protected $brand;
    protected $model;
    protected $year;
    protected $color;
    
    public function __construct($brand, $model, $year, $color) {
        $this->brand = $brand;
        $this->model = $model;
        $this->year = $year;
        $this->color = $color;
    }
    
    public function startEngine() {
        return "The $this->brand $this->model engine is starting...";
    }
    
    public function stopEngine() {
        return "The $this->brand $this->model engine is stopping...";
    }
    
    public function getInfo() {
        return "$this->year $this->color $this->brand $this->model";
    }
    
    public function getAge() {
        $currentYear = date("Y");
        return $currentYear - $this->year;
    }
}

// Child class - Car (inherits from Vehicle)
class Car extends Vehicle {
    private $doors;
    private $fuelType;
    
    public function __construct($brand, $model, $year, $color, $doors, $fuelType) {
        // Call parent constructor
        parent::__construct($brand, $model, $year, $color);
        
        // Initialize child-specific properties
        $this->doors = $doors;
        $this->fuelType = $fuelType;
    }
    
    // Override parent method
    public function startEngine() {
        return parent::startEngine() . " Vroom vroom! 🚗";
    }
    
    // Child-specific method
    public function honk() {
        return "Beep beep! 🎺";
    }
    
    public function openTrunk() {
        return "Trunk is now open.";
    }
    
    public function getCarInfo() {
        $basicInfo = $this->getInfo();
        return "$basicInfo, $this->doors doors, $this->fuelType engine";
    }
}

// Child class - Motorcycle (inherits from Vehicle)
class Motorcycle extends Vehicle {
    private $engineType;
    private $hasSidecar;
    
    public function __construct($brand, $model, $year, $color, $engineType, $hasSidecar = false) {
        parent::__construct($brand, $model, $year, $color);
        $this->engineType = $engineType;
        $this->hasSidecar = $hasSidecar;
    }
    
    // Override parent method
    public function startEngine() {
        return parent::startEngine() . " Vroooom! 🏍️";
    }
    
    // Child-specific method
    public function wheelie() {
        return "Performing a wheelie! 🎪";
    }
    
    public function lean($direction) {
        return "Leaning $direction into the turn.";
    }
    
    public function getMotorcycleInfo() {
        $basicInfo = $this->getInfo();
        $sidecarInfo = $this->hasSidecar ? "with sidecar" : "without sidecar";
        return "$basicInfo, $this->engineType engine, $sidecarInfo";
    }
}

// Grandchild class - ElectricCar (inherits from Car)
class ElectricCar extends Car {
    private $batteryCapacity;
    private $range;
    
    public function __construct($brand, $model, $year, $color, $doors, $batteryCapacity, $range) {
        // Call parent constructor (Car)
        parent::__construct($brand, $model, $year, $color, $doors, "Electric");
        
        $this->batteryCapacity = $batteryCapacity;
        $this->range = $range;
    }
    
    // Override parent method again
    public function startEngine() {
        return "The $this->brand $this->model electric motor is starting... ⚡";
    }
    
    // Grandchild-specific methods
    public function chargeBattery() {
        return "Charging the battery... 🔋";
    }
    
    public function getBatteryInfo() {
        return "Battery: $this->batteryCapacity kWh, Range: $this->range miles";
    }
    
    public function getElectricCarInfo() {
        $carInfo = $this->getCarInfo();
        $batteryInfo = $this->getBatteryInfo();
        return "$carInfo\n$batteryInfo";
    }
}

// Demonstration
echo "=== INHERITANCE DEMONSTRATION ===\n\n";

// Create parent object
$vehicle1 = new Vehicle("Generic", "Vehicle", 2020, "Black");

echo $vehicle1->getInfo() . "\n";

// Create child objects
echo "CHILD CLASSES:\n";
echo "===============\n\n";

echo "Car Information:\n";

echo "Motorcycle Information:\n";

echo $motorcycle1->startEngine() . "\n";
echo $motorcycle1->wheelie() . "\n";
echo $motorcycle1->lean("left") . "\n\n";

echo "GRANDCHILD CLASS:\n";
echo "==================\n\n";

Polymorphism

Polymorphism means "many forms" and allows objects of different types to be treated as objects of a common base type. The same method name can perform different tasks based on the object context.

Polymorphism Examples
<?php
// Abstract base class demonstrating polymorphism
abstract class Shape {
    protected $name;
    
    public function __construct($name) {
        $this->name = $name;
    }
    
    // Abstract method - must be implemented by child classes
    abstract public function calculateArea();
    abstract public function calculatePerimeter();
    
    // Concrete method - inherited by child classes
    public function getName() {
        return $this->name;
    }
    
    public function displayInfo() {
        $area = $this->calculateArea();
        $perimeter = $this->calculatePerimeter();
        return "Shape: $this->name, Area: $area, Perimeter: $perimeter";
    }
}

// Circle class
class Circle extends Shape {
    private $radius;
    
    public function __construct($radius) {
        parent::__construct("Circle");
        $this->radius = $radius;
    }
    
    // Implement abstract methods
    public function calculateArea() {
        return pi() * $this->radius * $this->radius;
    }
    
    public function calculatePerimeter() {
        return 2 * pi() * $this->radius;
    }
    
    // Circle-specific method
    public function getDiameter() {
        return 2 * $this->radius;
    }
}

// Rectangle class
class Rectangle extends Shape {
    private $width;
    private $height;
    
    public function __construct($width, $height) {
        parent::__construct("Rectangle");
        $this->width = $width;
        $this->height = $height;
    }
    
    // Implement abstract methods
    public function calculateArea() {
        return $this->width * $this->height;
    }
    
    public function calculatePerimeter() {
        return 2 * ($this->width + $this->height);
    }
    
    // Rectangle-specific method
    public function isSquare() {
        return $this->width === $this->height;
    }
}

// Triangle class
class Triangle extends Shape {
    private $side1;
    private $side2;
    private $side3;
    
    public function __construct($side1, $side2, $side3) {
        parent::__construct("Triangle");
        $this->side1 = $side1;
        $this->side2 = $side2;
        $this->side3 = $side3;
    }
    
    // Implement abstract methods
    public function calculateArea() {
        // Using Heron's formula
        $s = $this->calculatePerimeter() / 2;
        return sqrt($s * ($s - $this->side1) * ($s - $this->side2) * ($s - $this->side3));
    }
    
    public function calculatePerimeter() {
        return $this->side1 + $this->side2 + $this->side3;
    }
    
    // Triangle-specific method
    public function getTriangleType() {
        if ($this->side1 === $this->side2 && $this->side2 === $this->side3) {
            return "Equilateral";
        } elseif ($this->side1 === $this->side2 || $this->side2 === $this->side3 || $this->side1 === $this->side3) {
            return "Isosceles";
        } else {
            return "Scalene";
        }
    }
}

// Interface demonstrating polymorphism
interface Drawable {
    public function draw();
    public function getColor();
    public function setColor($color);
}

// Class implementing interface
class ColoredCircle extends Circle implements Drawable {
    private $color;
    
    public function __construct($radius, $color = "black") {
        parent::__construct($radius);
        $this->color = $color;
    }
    
    // Implement interface methods
    public function draw() {
        return "Drawing a $this->color circle with radius $this->radius";
    }
    
    public function getColor() {
        return $this->color;
    }
    
    public function setColor($color) {
        $this->color = $color;
    }
}

// Function demonstrating polymorphism
function processShape(Shape $shape) {
    echo $shape->displayInfo() . "\n";
    
    // Type-specific operations
    if ($shape instanceof Circle) {
        echo "Diameter: " . $shape->getDiameter() . "\n";
    } elseif ($shape instanceof Rectangle) {
        echo "Is Square: " . ($shape->isSquare() ? "Yes" : "No") . "\n";
    } elseif ($shape instanceof Triangle) {
        echo "Triangle Type: " . $shape->getTriangleType() . "\n";
    }
    
    echo "-" . str_repeat("-", 40) . "\n";
}

// Function for drawable objects
function drawObject(Drawable $obj) {
    echo $obj->draw() . "\n";
}

// Demonstration
echo "=== POLYMORPHISM DEMONSTRATION ===\n\n";

// Create different shape objects

    new ColoredCircle(3, "red")

// Method overloading simulation
echo "\n=== METHOD OVERLOADING SIMULATION ===\n\n";

class Calculator {
    // Same method name, different parameter types
    public function calculate($a, $b, $operation = "add") {
        switch($operation) {
            case "add":
                return $a + $b;
            case "subtract":
                return $a - $b;
            case "multiply":
                return $a * $b;
            case "divide":
                return $b != 0 ? $a / $b : "Cannot divide by zero";
            default:
                return "Invalid operation";
        }
    }
    
    // Method with different number of parameters
    public function calculateArea($shape, ...$params) {
        switch(strtolower($shape)) {
            case "circle":
                return pi() * $params[0] * $params[0];
            case "rectangle":
                return $params[0] * $params[1];
            case "triangle":
                return 0.5 * $params[0] * $params[1];
            default:
                return "Unknown shape";
        }
    }

<?php
// Interface for products
interface ProductInterface {
    public function getPrice();
    public function getDescription();
    public function isAvailable();
    public function applyDiscount($percentage);
}

// Interface for shippable items
interface ShippableInterface {
    public function getWeight();
    public function getDimensions();
    public function calculateShippingCost($distance);
}

// Interface for taxable items
interface TaxableInterface {
    public function calculateTax($taxRate);
}

// Abstract base class
abstract class Product implements ProductInterface {
    protected $sku;
    protected $name;
    protected $price;
    protected $description;
    protected $stock;
    
    public function __construct($sku, $name, $price, $description, $stock = 0) {
        $this->sku = $sku;
        $this->name = $name;
        $this->price = $price;
        $this->description = $description;
        $this->stock = $stock;
    }
    
    // Implement interface methods
    public function getPrice() {
        return $this->price;
    }
    
    public function getDescription() {
        return $this->description;
    }
    
    public function isAvailable() {
        return $this->stock > 0;
    }
    
    public function applyDiscount($percentage) {
        if ($percentage > 0 && $percentage <= 100) {
            $this->price -= $this->price * ($percentage / 100);
            return true;
        }
        return false;
    }
    
    // Abstract method for product-specific features
    abstract public function getProductType();
    
    // Common methods
    public function updateStock($quantity) {
        $this->stock += $quantity;
    }
    
    public function sell($quantity = 1) {
        if ($this->stock >= $quantity) {
            $this->stock -= $quantity;
            return true;
        }
        return false;
    }
    
    public function getStock() {
        return $this->stock;
    }
    
    public function getSku() {
        return $this->sku;
    }
    
    public function getName() {
        return $this->name;
    }
}

// Physical product class
class PhysicalProduct extends Product implements ShippableInterface, TaxableInterface {
    private $weight;
    private $length;
    private $width;
    private $height;
    
    public function __construct($sku, $name, $price, $description, $stock, $weight, $length, $width, $height) {
        parent::__construct($sku, $name, $price, $description, $stock);
        $this->weight = $weight;
        $this->length = $length;
        $this->width = $width;
        $this->height = $height;
    }
    
    // Implement ShippableInterface
    public function getWeight() {
        return $this->weight;
    }
    
    public function getDimensions() {
        return [$this->length, $this->width, $this->height];
    }
    
    public function calculateShippingCost($distance) {
        // Simple shipping calculation based on weight and distance
        $baseRate = 0.1; // $0.10 per mile per pound
        return $this->weight * $distance * $baseRate;
    }
    
    // Implement TaxableInterface
    public function calculateTax($taxRate) {
        return $this->price * ($taxRate / 100);
    }
    
    // Implement abstract method
    public function getProductType() {
        return "Physical Product";
    }
    
    // Physical product specific methods
    public function getVolume() {
        return $this->length * $this->width * $this->height;
    }
    
    public function isFragile() {
        return $this->weight < 5; // Simple fragile detection
    }
}

// Shopping cart class
class ShoppingCart {
    private $items = [];
    private $taxRate = 8.25; // 8.25% tax
    
    public function addItem(ProductInterface $product, $quantity = 1) {
        $sku = $product->getSku();
        if (isset($this->items[$sku])) {
            $this->items[$sku]['quantity'] += $quantity;
        } else {
            $this->items[$sku] = [
                'product' => $product,
                'quantity' => $quantity
            ];
        }
        echo "Added $quantity x " . $product->getName() . " to cart\n";
    }
    
    public function removeItem($sku) {
        if (isset($this->items[$sku])) {
            unset($this->items[$sku]);
            echo "Removed item from cart\n";
        }
    }
    
    public function updateQuantity($sku, $quantity) {
        if (isset($this->items[$sku])) {
            $this->items[$sku]['quantity'] = $quantity;
            echo "Updated quantity to $quantity\n";
        }
    }
    
    public function calculateSubtotal() {
        $subtotal = 0;
        foreach($this->items as $item) {
            $subtotal += $item['product']->getPrice() * $item['quantity'];
        }
        return $subtotal;
    }
    
    public function calculateTax() {
        $subtotal = $this->calculateSubtotal();
        $tax = 0;
        foreach($this->items as $item) {
            $product = $item['product'];
            if ($product instanceof TaxableInterface) {
                $tax += $product->calculateTax($this->taxRate) * $item['quantity'];
            }
        }
        return $tax;
    }
    
    public function calculateShipping($distance = 100) {
        $shipping = 0;
        foreach($this->items as $item) {
            $product = $item['product'];
            if ($product instanceof ShippableInterface) {
                $shipping += $product->calculateShippingCost($distance) * $item['quantity'];
            }
        }
        return $shipping;
    }
    
    public function calculateTotal($distance = 100) {
        $subtotal = $this->calculateSubtotal();
        $tax = $this->calculateTax();
        $shipping = $this->calculateShipping($distance);
        return $subtotal + $tax + $shipping;
    }
    
    public function displayCart() {
        echo "SHOPPING CART\n";
        echo "=============\n\n";
        
        if (empty($this->items)) {
            echo "Cart is empty\n";
            return;
        }
        
        foreach($this->items as $sku => $item) {
            $product = $item['product'];
            $quantity = $item['quantity'];
            $price = $product->getPrice();
            $total = $price * $quantity;
            
            echo sprintf("%-20s x%-3d $%8.2f $%8.2f\n", 
                $product->getName(), $quantity, $price, $total);
        }
        
        echo "\nSubtotal: $" . number_format($this->calculateSubtotal(), 2) . "\n";
        echo "Tax: $" . number_format($this->calculateTax(), 2) . "\n";
        echo "Shipping: $" . number_format($this->calculateShipping(), 2) . "\n";
        echo "TOTAL: $" . number_format($this->calculateTotal(), 2) . "\n";
    }
}
