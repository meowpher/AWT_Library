Evolution of PHP

PHP began as the Personal Home Page and has evolved into one of the most popular server-side scripting languages on the web.

Key Milestones:

  • 1994: Developed by Rasmus Lerdorf as Personal Home Page
  • 1997: PHP 2 released (PHP now stands for Hypertext Preprocessor)
  • 1998: PHP 3 released with improved functionality
  • 2000: PHP 4 released with Zend Engine
  • 2004: PHP 5.0.0 released with major OOP improvements
  • 2015: PHP 7 released with significant performance improvements
  • 2020: PHP 8 released with JIT compilation and new features

Today, PHP powers over 70% of websites on the internet, including major platforms like WordPress, Facebook, and Wikipedia.

Features of PHP

Server-Side Scripting

PHP scripts are executed on the server, generating dynamic HTML content sent to the client.

Open Source

Free to use, modify, and distribute with a large community support.

Database Integration

Excellent support for MySQL, PostgreSQL, Oracle, and other databases.

Cross-Platform

Runs on Windows, Linux, macOS, and various Unix systems.

Key Strengths:

  • • Easy to learn with C-like syntax
  • • Large collection of built-in functions
  • • Excellent performance and scalability
  • • Strong security features
  • • Extensive documentation and community

Advantages of PHP

Platform Independence

Runs on various platforms and is compatible with almost all web servers.

Dynamic Content Generation

Can generate dynamic page content based on user input and database queries.

File Operations

Can create, open, read, write, delete, and close files on the server.

Form Handling

Excellent support for collecting form data and processing user input.

Basic PHP Syntax

PHP Syntax Example
<?php
// PHP code starts with <?php and ends with ?>
echo "Hello, World!";

// All PHP statements end with a semicolon
$name = "PHP";
echo "Welcome to $name programming!";

// PHP can be embedded in HTML
?>
<html>
<body>
    <h1><?php echo "Dynamic Content"; ?></h1>
</body>
</html>

Important Notes:

  • • PHP files have a .php extension
  • • PHP code is executed on the server
  • • PHP is structurally similar to C/C++
  • • Supports both procedural and object-oriented programming
  • • All statements must end with a semicolon (;)

Comments in PHP

Comments are lines that are not executed as part of the program. They are used to explain code and make it more readable.

PHP Comments Example
<?php
// Single line comment using double slash
# Single line comment using hash symbol

/*
Multi-line comment
This can span multiple lines
Used for detailed explanations
*/

// Comments help others understand your code
$name = "John"; // This is an inline comment
$age = 25; # Another inline comment

/*
Function: calculateSum
Purpose: Adds two numbers
Parameters: $a, $b
Returns: Sum of $a and $b
*/
function calculateSum($a, $b) {
    return $a + $b; // Return the sum
}
?>

Best Practices:

  • • Use comments to explain complex logic
  • • Comment your functions with purpose and parameters
  • • Keep comments up to date with code changes
  • • Use meaningful variable names to reduce comment needs

Echo vs Print Statements

Both echo and print are used to output data in PHP, but they have some key differences.

Feature echo print
Return Value No return value Returns 1 (can be used in expressions)
Parameters Can take multiple parameters Can take only one parameter
Performance Marginally faster Slightly slower
Syntax echo or echo() print or print()
Echo and Print Examples
<?php
// Echo examples
echo "Hello, World!";
echo "This is a string";
echo "Multiple ", "parameters ", "with echo";

// Print examples
print "Hello, World!";
print "This is also a string";

// Using in expressions (print only)
$result = print "This can be used in expressions";
// $result will be 1

// Parentheses can be used with both
echo("Hello with parentheses");
print("Hello with parentheses");

// Variables with echo and print
$name = "PHP";
echo "Welcome to $name!";
print "Welcome to $name!";
?>

Variables in PHP

Variables are used to store data values. In PHP, variables start with the $ symbol followed by the variable name.

Variable Rules:

  • • Must start with $ symbol
  • • Must start with a letter or underscore (not number)
  • • Can only contain alphanumeric characters and underscores
  • • Case-sensitive ($name is different from $Name)
  • • Cannot use reserved keywords
PHP Variables Example
<?php
// Valid variable names
$name = "John Doe";
$age = 25;
$city = "New York";
$_score = 95;
$user123 = "student123";

// Invalid variable names (will cause errors)
// $123name = "Invalid";    // Cannot start with number
// $user-name = "Invalid";   // Cannot contain hyphen
// $class = "Invalid";       // Case sensitive

// Variable types
$string = "Hello, World!";
$integer = 42;
$float = 3.14;
$boolean = true;
$array = array(1, 2, 3);

// Output variables
echo "Name: $name
";
echo "Age: $age
";
echo "City: $city
";

// Variable interpolation
$greeting = "Hello";
$name = "PHP Developer";
echo "$greeting, $name!";
?>

Variable Scope:

  • • Global variables: Can be used anywhere in the script
  • • Local variables: Restricted to functions or classes
  • • Static variables: Retain their value between function calls
