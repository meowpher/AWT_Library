Introduction to File Handling

File handling is an important part of any web application. PHP provides powerful functions for creating, reading, writing, and manipulating files and directories on the server.

Common File Operations:

  • • fopen(): Open a file for reading, writing, or appending
  • • fread(): Read content from an open file
  • • fwrite(): Write content to an open file
  • • fclose(): Close an open file
  • • file_get_contents(): Read entire file into a string
  • • file_put_contents(): Write string to a file

File Operations

PHP provides various functions for performing operations on files. Here's a comprehensive overview of the most commonly used file operations:

File Access

  • • fopen() - Open file
  • • fclose() - Close file
  • • feof() - Check end of file
  • • fseek() - Seek to position
  • • rewind() - Rewind file pointer
  • • ftell() - Get file position

File Information

  • • file_exists() - Check if file exists
  • • filesize() - Get file size
  • • is_file() - Check if regular file
  • • is_dir() - Check if directory
  • • is_readable() - Check readability
  • • is_writable() - Check writability

File Manipulation

  • • copy() - Copy file
  • • rename() - Rename file
  • • unlink() - Delete file
  • • mkdir() - Create directory
  • • rmdir() - Remove directory
  • • scandir() - List directory contents

Path Functions

  • • basename() - Get filename
  • • dirname() - Get directory path
  • • pathinfo() - Get path information
  • • realpath() - Get absolute path
  • • glob() - Find pathnames matching pattern

File Operation Flow:

1 Check if file exists (file_exists())
2 Open file with appropriate mode (fopen())
3 Perform read/write operations
4 Check for errors (if any)
5 Close file (fclose())

File Opening Modes

The fopen() function requires a mode parameter that specifies how the file should be opened. Each mode has different characteristics and use cases.

Mode Description File Pointer Position Creates File?
'r' Read only Beginning of file No
'r+' Read and write Beginning of file No
'w' Write only Beginning of file Yes
'w+' Read and write Beginning of file Yes
'a' Append only End of file Yes
'a+' Read and append End of file Yes
'x' Create and write only Beginning of file Yes (fails if exists)
'x+' Create and read/write Beginning of file Yes (fails if exists)

Important Notes:

  • • 'w' and 'w+' modes truncate the file to zero length if it exists
  • • 'a' and 'a+' modes preserve existing content and append to the end
  • • 'x' and 'x+' modes fail if the file already exists
  • • Add 'b' for binary mode (e.g., 'rb', 'wb+') on Windows systems
  • • Add 't' for text mode on Windows systems

Reading Files

PHP provides several methods to read content from files. The choice of method depends on the file size and the specific requirements of your application.

File Reading Examples
<?php
// Method 1: Reading entire file at once
function readFileAll($filename) {
    if (file_exists($filename)) {
        $content = file_get_contents($filename);
        return $content;
    } else {
        return "File does not exist";
    }
}

// Method 2: Reading file line by line
function readFileLineByLine($filename) {
    $lines = [];
    if (file_exists($filename)) {
        $file = fopen($filename, "r");
        if ($file) {
            while (!feof($file)) {
                $line = fgets($file);
                if ($line !== false) {
                    $lines[] = trim($line);
                }
            }
            fclose($file);
        }
    }
    return $lines;
}

// Method 3: Reading file character by character
function readFileCharByChar($filename) {
    $content = "";
    if (file_exists($filename)) {
        $file = fopen($filename, "r");
        if ($file) {
            while (!feof($file)) {
                $char = fgetc($file);
                if ($char !== false) {
                    $content .= $char;
                }
            }
            fclose($file);
        }
    }
    return $content;
}

// Method 4: Reading specific number of bytes
function readFileChunk($filename, $chunkSize = 1024) {
    $content = "";
    if (file_exists($filename)) {
        $file = fopen($filename, "r");
        if ($file) {
            while (!feof($file)) {
                $chunk = fread($file, $chunkSize);
                if ($chunk !== false) {
                    $content .= $chunk;
                }
            }
            fclose($file);
        }
    }
    return $content;
}

// Method 5: Reading CSV file
function readCSVFile($filename) {
    $data = [];
    if (file_exists($filename)) {
        $file = fopen($filename, "r");
        if ($file) {
            while (($row = fgetcsv($file)) !== false) {
                $data[] = $row;
            }
            fclose($file);
        }
    }
    return $data;
}

// Method 6: Reading JSON file
function readJSONFile($filename) {
    if (file_exists($filename)) {
        $content = file_get_contents($filename);
        return json_decode($content, true);
    }
    return null;
}

// Method 7: Reading file with error handling
function readFileWithErrorHandling($filename) {
    try {
        if (!file_exists($filename)) {
            throw new Exception("File not found: $filename");
        }
        
        if (!is_readable($filename)) {
            throw new Exception("File is not readable: $filename");
        }
        
        $content = file_get_contents($filename);
        
        if ($content === false) {
            throw new Exception("Failed to read file: $filename");
        }
        
        return $content;
        
    } catch (Exception $e) {
        return "Error: " . $e->getMessage();
    }
}

// Method 8: Reading large files efficiently
function readLargeFile($filename, $callback, $chunkSize = 8192) {
    if (file_exists($filename)) {
        $file = fopen($filename, "r");
        if ($file) {
            while (!feof($file)) {
                $chunk = fread($file, $chunkSize);
                if ($chunk !== false) {
                    call_user_func($callback, $chunk);
                }
            }
            fclose($file);
        }
    }
}

Best Practices for File Reading:

  • • Always check if file exists before reading
  • • Use file_get_contents() for small files
  • • Use fopen()/fread() for large files to avoid memory issues
  • • Always close files after use with fclose()
  • • Handle errors gracefully with try-catch blocks
  • • Use appropriate methods for specific file types (CSV, JSON)

Writing Files

PHP provides several methods to write content to files. The choice of method depends on whether you want to overwrite, append, or create new files.

File Writing Examples
<?php
// Method 1: Writing entire file at once
function writeFileAll($filename, $content, $append = false) {
    $flags = $append ? FILE_APPEND : 0;
    return file_put_contents($filename, $content, $flags);
}

// Method 2: Writing line by line
function writeFileLineByLine($filename, $lines, $mode = "w") {
    $file = fopen($filename, $mode);
    if ($file) {
        foreach($lines as $line) {
            fwrite($file, $line . PHP_EOL);
        }
        fclose($file);
        return true;
    }
    return false;
}

// Method 3: Writing with different modes
function writeWithModes($filename) {
    // Write mode (truncates existing file)
    $file1 = fopen($filename . "_write.txt", "w");
    fwrite($file1, "This overwrites any existing content\n");
    fwrite($file1, "Second line of content\n");
    fclose($file1);
    
    // Append mode (preserves existing content)
    $file2 = fopen($filename . "_append.txt", "a");
    fwrite($file2, "This gets appended to existing content\n");
    fwrite($file2, "Another appended line\n");
    fclose($file2);
    
    // Create mode (fails if file exists)
    $newFilename = $filename . "_create.txt";
    if (!file_exists($newFilename)) {
        $file3 = fopen($newFilename, "x");
        if ($file3) {
            fwrite($file3, "This creates a new file\n");
            fwrite($file3, "Only works if file doesn't exist\n");
            fclose($file3);
        }
    }
}

// Method 4: Writing CSV file
function writeCSVFile($filename, $data) {
    $file = fopen($filename, "w");
    if ($file) {
        foreach($data as $row) {
            fputcsv($file, $row);
        }
        fclose($file);
        return true;
    }
    return false;
}

// Method 5: Writing JSON file
function writeJSONFile($filename, $data) {
    $jsonContent = json_encode($data, JSON_PRETTY_PRINT);
    return file_put_contents($filename, $jsonContent);
}

// Method 6: Writing log files
function writeLog($message, $logFile = "app.log") {
    $timestamp = date("Y-m-d H:i:s");
    $logEntry = "[$timestamp] $message" . PHP_EOL;
    return file_put_contents($logFile, $logEntry, FILE_APPEND | LOCK_EX);
}

// Method 7: Writing binary files
function writeBinaryFile($filename, $binaryData) {
    $file = fopen($filename, "wb");
    if ($file) {
        fwrite($file, $binaryData);
        fclose($file);
        return true;
    }
    return false;
}

// Method 8: Writing with file locking
function writeWithLock($filename, $content) {
    $file = fopen($filename, "c");
    if ($file) {
        if (flock($file, LOCK_EX)) { // Exclusive lock
            ftruncate($file, 0); // Clear file
            rewind($file); // Rewind to beginning
            fwrite($file, $content);
            fflush($file); // Flush output
            flock($file, LOCK_UN); // Release lock
        }
        fclose($file);
        return true;
    }
    return false;
}

// Method 10: Writing with progress tracking
function writeLargeFile($filename, $content, $chunkSize = 8192) {
    $file = fopen($filename, "w");
    if ($file) {
        $totalSize = strlen($content);
        $written = 0;
        
        for ($i = 0; $i < $totalSize; $i += $chunkSize) {
            $chunk = substr($content, $i, $chunkSize);
            $bytesWritten = fwrite($file, $chunk);
            
            if ($bytesWritten === false) {
                fclose($file);
                return false;
            }
            
            $written += $bytesWritten;
            $progress = ($written / $totalSize) * 100;
            echo sprintf("Progress: %.2f%%\r", $progress);
        }

        echo "\nWrite completed successfully!\n";
        return true;
    }
    return false;
}

Working with Directories

PHP provides functions for creating, reading, and manipulating directories. Directory operations are essential for organizing files and managing file structures.

Directory Operations Examples
<?php
// Function to create directory structure
function createDirectoryStructure($basePath, $structure) {
    foreach($structure as $dir => $subdirs) {
        $path = $basePath . DIRECTORY_SEPARATOR . $dir;
        
        if (!is_dir($path)) {
            if (mkdir($path, 0755, true)) {
                echo "Created directory: $path\n";
            } else {
                echo "Failed to create directory: $path\n";
            }
        }
        
        if (is_array($subdirs) && !empty($subdirs)) {
            createDirectoryStructure($path, $subdirs);
        }
    }
}

// Function to list directory contents
function listDirectoryContents($path, $recursive = false) {
    $contents = [
        'files' => [],
        'directories' => []
    ];
    
    if (is_dir($path)) {
        $items = scandir($path);
        
        foreach($items as $item) {
            if ($item === '.' || $item === '..') {
                continue;
            }
            
            $fullPath = $path . DIRECTORY_SEPARATOR . $item;
            
            if (is_file($fullPath)) {
                $contents['files'][] = [
                    'name' => $item,
                    'path' => $fullPath,
                    'size' => filesize($fullPath),
                    'modified' => date("Y-m-d H:i:s", filemtime($fullPath))
                ];
            } elseif (is_dir($fullPath)) {
                $contents['directories'][] = [
                    'name' => $item,
                    'path' => $fullPath
                ];
                
                if ($recursive) {
                    $subContents = listDirectoryContents($fullPath, true);
                    $contents['files'] = array_merge($contents['files'], $subContents['files']);
                    $contents['directories'] = array_merge($contents['directories'], $subContents['directories']);
                }
            }
        }
    }
    
    return $contents;
}

// Function to calculate directory size
function getDirectorySize($path) {
    $totalSize = 0;
    
    if (is_dir($path)) {
        $items = scandir($path);
        
        foreach($items as $item) {
            if ($item === '.' || $item === '..') {
                continue;
            }
            
            $fullPath = $path . DIRECTORY_SEPARATOR . $item;
            
            if (is_file($fullPath)) {
                $totalSize += filesize($fullPath);
            } elseif (is_dir($fullPath)) {
                $totalSize += getDirectorySize($fullPath);
            }
        }
    }
    
    return $totalSize;
}

// Function to copy directory recursively
function copyDirectory($source, $destination) {
    if (!is_dir($source)) {
        return false;
    }
    
    if (!is_dir($destination)) {
        mkdir($destination, 0755, true);
    }
    
    $items = scandir($source);
    
    foreach($items as $item) {
        if ($item === '.' || $item === '..') {
            continue;
        }
        
        $sourcePath = $source . DIRECTORY_SEPARATOR . $item;
        $destPath = $destination . DIRECTORY_SEPARATOR . $item;
        
        if (is_file($sourcePath)) {
            copy($sourcePath, $destPath);
        } elseif (is_dir($sourcePath)) {
            copyDirectory($sourcePath, $destPath);
        }
    }
    
    return true;
}

// Function to delete directory recursively
function deleteDirectory($path) {
    if (!is_dir($path)) {
        return false;
    }
    
    $items = scandir($path);
    
    foreach($items as $item) {
        if ($item === '.' || $item === '..') {
            continue;
        }
        
        $fullPath = $path . DIRECTORY_SEPARATOR . $item;
        
        if (is_file($fullPath)) {
            unlink($fullPath);
        } elseif (is_dir($fullPath)) {
            deleteDirectory($fullPath);
        }
    }
    
    return rmdir($path);
}

// Function to find files by pattern
function findFiles($pattern, $path = '.') {
    $matches = [];
    $files = glob($path . DIRECTORY_SEPARATOR . $pattern);
    
    foreach($files as $file) {
        if (is_file($file)) {
            $matches[] = $file;
        }
    }
    
    // Search in subdirectories
    $dirs = glob($path . DIRECTORY_SEPARATOR . '*', GLOB_ONLYDIR);
    foreach($dirs as $dir) {
        if ($dir !== '.' && $dir !== '..') {
            $subMatches = findFiles($pattern, $dir);
            $matches = array_merge($matches, $subMatches);
        }
    }
    
    return $matches;
}

// Function to create file index
function createFileIndex($path, $indexFile = "file_index.txt") {
    $contents = listDirectoryContents($path, true);
    $indexContent = "FILE INDEX\n";
    $indexContent .= "Generated: " . date("Y-m-d H:i:s") . "\n";
    $indexContent .= "Path: $path\n";
    $indexContent .= str_repeat("=", 50) . "\n\n";
    
    // Add directories
    if (!empty($contents['directories'])) {
        $indexContent .= "DIRECTORIES:\n";
        foreach($contents['directories'] as $dir) {
            $indexContent .= "  [DIR] " . $dir['name'] . "\n";
        }
        $indexContent .= "\n";
    }
    
    // Add files
    if (!empty($contents['files'])) {
        $indexContent .= "FILES:\n";
        foreach($contents['files'] as $file) {
            $indexContent .= sprintf("  %-30s %8s bytes %s\n", 
                $file['name'], 
                number_format($file['size']), 
                $file['modified']
            );
        }
    }
    
    return file_put_contents($indexFile, $indexContent);
}

File uploads are a common feature in web applications. PHP provides the $_FILES superglobal array to handle uploaded files securely.

File Upload Handling
<?php
// File upload handler class
class FileUploader {
    private $uploadDir;
    private $allowedExtensions;
    private $maxFileSize;
    private $allowedMimeTypes;
    
    public function __construct($uploadDir = "uploads", $maxFileSize = 10485760) {
        $this->uploadDir = $uploadDir;
        $this->maxFileSize = $maxFileSize;
        $this->allowedExtensions = [];
        $this->allowedMimeTypes = [];
        
        // Create upload directory if it doesn't exist
        if (!is_dir($this->uploadDir)) {
            mkdir($this->uploadDir, 0755, true);
        }
    }
    
    public function setAllowedExtensions($extensions) {
        $this->allowedExtensions = array_map('strtolower', $extensions);
    }
    
    public function setAllowedMimeTypes($mimeTypes) {
        $this->allowedMimeTypes = $mimeTypes;
    }
    
    public function uploadFile($fileInputName, $customFilename = null) {
        // Check if file was uploaded
        if (!isset($_FILES[$fileInputName])) {
            return ['success' => false, 'error' => 'No file uploaded'];
        }
        
        $file = $_FILES[$fileInputName];
        
        // Check for upload errors
        if ($file['error'] !== UPLOAD_ERR_OK) {
            return ['success' => false, 'error' => $this->getUploadErrorMessage($file['error'])];
        }
        
        // Validate file size
        if ($file['size'] > $this->maxFileSize) {
            return ['success' => false, 'error' => 'File size exceeds maximum allowed size'];
        }
        
        // Get file extension
        $fileExtension = strtolower(pathinfo($file['name'], PATHINFO_EXTENSION));
        
        // Validate file extension
        if (!empty($this->allowedExtensions) && !in_array($fileExtension, $this->allowedExtensions)) {
            return ['success' => false, 'error' => 'File type not allowed'];
        }
        
        // Validate MIME type
        $fileMimeType = mime_content_type($file['tmp_name']);
        if (!empty($this->allowedMimeTypes) && !in_array($fileMimeType, $this->allowedMimeTypes)) {
            return ['success' => false, 'error' => 'File MIME type not allowed'];
        }
        
        // Generate filename
        if ($customFilename) {
            $filename = $customFilename . '.' . $fileExtension;
        } else {
            $filename = $this->generateUniqueFilename($file['name']);
        }
        
        $uploadPath = $this->uploadDir . DIRECTORY_SEPARATOR . $filename;
        
        // Move uploaded file
        if (move_uploaded_file($file['tmp_name'], $uploadPath)) {
            // Set proper permissions
            chmod($uploadPath, 0644);
            
            return [
                'success' => true,
                'filename' => $filename,
                'filepath' => $uploadPath,
                'size' => $file['size'],
                'mime_type' => $fileMimeType,
                'extension' => $fileExtension
            ];
        } else {
            return ['success' => false, 'error' => 'Failed to move uploaded file'];
        }
    }
    
    private function generateUniqueFilename($originalName) {
        $extension = pathinfo($originalName, PATHINFO_EXTENSION);
        $basename = pathinfo($originalName, PATHINFO_FILENAME);
        $basename = preg_replace('/[^a-zA-Z0-9_-]/', '', $basename);
        
        if (empty($basename)) {
            $basename = 'file';
        }
        
        $filename = $basename . '_' . uniqid() . '.' . $extension;
        
        // Ensure filename doesn't already exist
        while (file_exists($this->uploadDir . DIRECTORY_SEPARATOR . $filename)) {
            $filename = $basename . '_' . uniqid() . '.' . $extension;
        }
        
        return $filename;
    }
    
    private function getUploadErrorMessage($errorCode) {
        $errors = [
            UPLOAD_ERR_INI_SIZE => 'File size exceeds upload_max_filesize directive',
            UPLOAD_ERR_FORM_SIZE => 'File size exceeds MAX_FILE_SIZE directive',
            UPLOAD_ERR_PARTIAL => 'File was only partially uploaded',
            UPLOAD_ERR_NO_FILE => 'No file was uploaded',
            UPLOAD_ERR_NO_TMP_DIR => 'Missing temporary folder',
            UPLOAD_ERR_CANT_WRITE => 'Failed to write file to disk',
            UPLOAD_ERR_EXTENSION => 'A PHP extension stopped the file upload'
        ];
        
        return isset($errors[$errorCode]) ? $errors[$errorCode] : 'Unknown upload error';
    }
    
    public function deleteFile($filename) {
        $filepath = $this->uploadDir . DIRECTORY_SEPARATOR . $filename;
        if (file_exists($filepath)) {
            return unlink($filepath);
        }
        return false;
    }
    
    public function getUploadedFiles() {
        $files = [];
        if (is_dir($this->uploadDir)) {
            $items = scandir($this->uploadDir);
            foreach($items as $item) {
                if ($item !== '.' && $item !== '..') {
                    $filepath = $this->uploadDir . DIRECTORY_SEPARATOR . $item;
                    if (is_file($filepath)) {
                        $files[] = [
                            'name' => $item,
                            'path' => $filepath,
                            'size' => filesize($filepath),
                            'modified' => date("Y-m-d H:i:s", filemtime($filepath))
                        ];
                    }
                }
            }
        }
        return $files;
    }
}

// Image upload handler class
class ImageUploader extends FileUploader {
    private $maxWidth;
    private $maxHeight;
    private $quality;
    
    public function __construct($uploadDir = "uploads/images", $maxFileSize = 5242880) {
        parent::__construct($uploadDir, $maxFileSize);
        $this->setAllowedExtensions(['jpg', 'jpeg', 'png', 'gif', 'webp']);
        $this->setAllowedMimeTypes([
            'image/jpeg', 'image/png', 'image/gif', 'image/webp'
        ]);
        $this->maxWidth = 1920;
        $this->maxHeight = 1080;
        $this->quality = 85;
    }
    
    public function resizeImage($sourcePath, $destPath, $maxWidth = null, $maxHeight = null, $quality = null) {
        $maxWidth = $maxWidth ?: $this->maxWidth;
        $maxHeight = $maxHeight ?: $this->maxHeight;
        $quality = $quality ?: $this->quality;
        
        // Get image information
        $imageInfo = getimagesize($sourcePath);
        if (!$imageInfo) {
            return false;
        }
        
        $width = $imageInfo[0];
        $height = $imageInfo[1];
        $mimeType = $imageInfo['mime'];
        
        // Calculate new dimensions
        $ratio = min($maxWidth / $width, $maxHeight / $height);
        $newWidth = round($width * $ratio);
        $newHeight = round($height * $ratio);
        
        // Create image resource
        switch($mimeType) {
            case 'image/jpeg':
                $sourceImage = imagecreatefromjpeg($sourcePath);
                break;
            case 'image/png':
                $sourceImage = imagecreatefrompng($sourcePath);
                break;
            case 'image/gif':
                $sourceImage = imagecreatefromgif($sourcePath);
                break;
            case 'image/webp':
                $sourceImage = imagecreatefromwebp($sourcePath);
                break;
            default:
                return false;
        }
        
        if (!$sourceImage) {
            return false;
        }
        
        // Create new image
        $newImage = imagecreatetruecolor($newWidth, $newHeight);
        
        // Preserve transparency for PNG and GIF
        if ($mimeType === 'image/png' || $mimeType === 'image/gif') {
            imagecolortransparent($newImage, imagecolorallocatealpha($newImage, 0, 0, 0, 127));
            imagealphablending($newImage, false);
            imagesavealpha($newImage, true);
        }
        
        // Resize image
        imagecopyresampled($newImage, $sourceImage, 0, 0, 0, 0, $newWidth, $newHeight, $width, $height);
        
        // Save resized image
        $result = false;
        switch($mimeType) {
            case 'image/jpeg':
                $result = imagejpeg($newImage, $destPath, $quality);
                break;
            case 'image/png':
                $result = imagepng($newImage, $destPath, round(9 * (100 - $quality) / 100));
                break;
            case 'image/gif':
                $result = imagegif($newImage, $destPath);
                break;
            case 'image/webp':
                $result = imagewebp($newImage, $destPath, $quality);
                break;
        }
        
        // Clean up
        imagedestroy($sourceImage);
        imagedestroy($newImage);
        
        return $result;
    }
    
    public function createThumbnail($sourcePath, $thumbPath, $thumbWidth = 150, $thumbHeight = 150) {
        return $this->resizeImage($sourcePath, $thumbPath, $thumbWidth, $thumbHeight, 75);
    }
}

class SimpleFileManager {
    private $basePath;
    private $currentPath;
    
    public function __construct($basePath = '.') {
        $this->basePath = realpath($basePath);
        $this->currentPath = $this->basePath;
    }
    
    public function listFiles() {
        $files = [];
        $directories = [];
        
        if (is_dir($this->currentPath)) {
            $items = scandir($this->currentPath);
            
            foreach($items as $item) {
                if ($item === '.' || $item === '..') {
                    continue;
                }
                
                $fullPath = $this->currentPath . DIRECTORY_SEPARATOR . $item;
                
                if (is_file($fullPath)) {
                    $files[] = [
                        'name' => $item,
                        'size' => filesize($fullPath),
                        'modified' => filemtime($fullPath),
                        'type' => 'file'
                    ];
                } elseif (is_dir($fullPath)) {
                    $directories[] = [
                        'name' => $item,
                        'modified' => filemtime($fullPath),
                        'type' => 'directory'
                    ];
                }
            }
        }
        
        // Sort: directories first, then files
        usort($directories, function($a, $b) {
            return strcmp($a['name'], $b['name']);
        });
        
        usort($files, function($a, $b) {
            return strcmp($a['name'], $b['name']);
        });
        
        return array_merge($directories, $files);
    }
    
    public function changeDirectory($directory) {
        $newPath = $this->currentPath . DIRECTORY_SEPARATOR . $directory;
        $newPath = realpath($newPath);
        
        if ($newPath && strpos($newPath, $this->basePath) === 0) {
            $this->currentPath = $newPath;
            return true;
        }
        
        return false;
    }
    
    public function getCurrentPath() {
        return $this->currentPath;
    }
    
    public function getRelativePath() {
        return str_replace($this->basePath, '', $this->currentPath);
    }
    
    public function createFile($filename, $content = '') {
        $filepath = $this->currentPath . DIRECTORY_SEPARATOR . $filename;
        
        if (file_exists($filepath)) {
            return false;
        }
        
        return file_put_contents($filepath, $content) !== false;
    }
    
    public function createDirectory($dirname) {
        $dirpath = $this->currentPath . DIRECTORY_SEPARATOR . $dirname;
        
        if (is_dir($dirpath)) {
            return false;
        }
        
        return mkdir($dirpath, 0755);
    }
    
    public function deleteFile($filename) {
        $filepath = $this->currentPath . DIRECTORY_SEPARATOR . $filename;
        
        if (!file_exists($filepath)) {
            return false;
        }
        
        return unlink($filepath);
    }
    
    public function deleteDirectory($dirname) {
        $dirpath = $this->currentPath . DIRECTORY_SEPARATOR . $dirname;
        
        if (!is_dir($dirpath)) {
            return false;
        }
        
        // Check if directory is empty
        $items = scandir($dirpath);
        foreach($items as $item) {
            if ($item !== '.' && $item !== '..') {
                return false; // Directory not empty
            }
        }
        
        return rmdir($dirpath);
    }
    
    public function renameItem($oldName, $newName) {
        $oldPath = $this->currentPath . DIRECTORY_SEPARATOR . $oldName;
        $newPath = $this->currentPath . DIRECTORY_SEPARATOR . $newName;
        
        if (!file_exists($oldPath) || file_exists($newPath)) {
            return false;
        }
        
        return rename($oldPath, $newPath);
    }
    
    public function readFile($filename) {
        $filepath = $this->currentPath . DIRECTORY_SEPARATOR . $filename;
        
        if (!is_file($filepath)) {
            return false;
        }
        
        return file_get_contents($filepath);
    }
    
    public function writeFile($filename, $content) {
        $filepath = $this->currentPath . DIRECTORY_SEPARATOR . $filename;
        
        return file_put_contents($filepath, $content) !== false;
    }
    
    public function getFileInfo($filename) {
        $filepath = $this->currentPath . DIRECTORY_SEPARATOR . $filename;
        
        if (!file_exists($filepath)) {
            return false;
        }
        
        return [
            'name' => basename($filepath),
            'path' => $filepath,
            'size' => filesize($filepath),
            'modified' => filemtime($filepath),
            'permissions' => substr(sprintf('%o', fileperms($filepath)), -4),
            'is_readable' => is_readable($filepath),
            'is_writable' => is_writable($filepath),
            'is_executable' => is_executable($filepath)
        ];
    }
}

Configuration Management
<?php
class ConfigManager {
    private $configDir;
    private $configFile;
    private $configData;
    
    public function __construct($configName = 'app') {
        $this->configDir = 'config';
        $this->configFile = $this->configDir . DIRECTORY_SEPARATOR . $configName . '.json';
        $this->configData = [];
        
        // Create config directory if it doesn't exist
        if (!is_dir($this->configDir)) {
            mkdir($this->configDir, 0755, true);
        }
        
        // Load existing configuration
        $this->loadConfig();
    }
    
    public function loadConfig() {
        if (file_exists($this->configFile)) {
            $content = file_get_contents($this->configFile);
            $this->configData = json_decode($content, true) ?: [];
        }
        return $this->configData;
    }
    
    public function saveConfig() {
        $content = json_encode($this->configData, JSON_PRETTY_PRINT | JSON_UNESCAPED_SLASHES);
        return file_put_contents($this->configFile, $content) !== false;
    }
    
    public function get($key, $default = null) {
        $keys = explode('.', $key);
        $data = $this->configData;
        
        foreach($keys as $k) {
            if (!isset($data[$k])) {
                return $default;
            }
            $data = $data[$k];
        }
        
        return $data;
    }
    
    public function set($key, $value) {
        $keys = explode('.', $key);
        $data = &$this->configData;
        
        foreach($keys as $i => $k) {
            if (count($keys) === 1) {
                break;
            }
            
            unset($keys[$i]);
            
            if (!isset($data[$k]) || !is_array($data[$k])) {
                $data[$k] = [];
            }
            
            $data = &$data[$k];
        }
        
        $data[array_shift($keys)] = $value;
        return $this->saveConfig();
    }
    
    public function has($key) {
        return $this->get($key) !== null;
    }
    
    public function remove($key) {
        $keys = explode('.', $key);
        $data = &$this->configData;
        
        foreach($keys as $i => $k) {
            if (count($keys) === 1) {
                break;
            }
            
            unset($keys[$i]);
            
            if (!isset($data[$k]) || !is_array($data[$k])) {
                return false;
            }
            
            $data = &$data[$k];
        }
        
        $key = array_shift($keys);
        if (isset($data[$key])) {
            unset($data[$key]);
            return $this->saveConfig();
        }
        
        return false;
    }
    
    public function all() {
        return $this->configData;
    }
    
    public function clear() {
        $this->configData = [];
        return $this->saveConfig();
    }
    
    public function merge($data) {
        $this->configData = array_merge_recursive($this->configData, $data);
        return $this->saveConfig();
    }
    
    public function export($format = 'json') {
        switch(strtolower($format)) {
            case 'json':
                return json_encode($this->configData, JSON_PRETTY_PRINT);
            
            case 'php':
                return "configData, true) . ";\n";
            
            case 'ini':
                $iniContent = "; Configuration file\n; Generated on " . date('Y-m-d H:i:s') . "\n\n";
                return $iniContent . $this->arrayToIni($this->configData);
            
            default:
                return json_encode($this->configData);
        }
    }
    
    private function arrayToIni($array, $parentKey = '') {
        $ini = '';
        
        foreach($array as $key => $value) {
            $fullKey = $parentKey ? $parentKey . '.' . $key : $key;
            
            if (is_array($value)) {
                if (is_numeric($key)) {
                    $ini .= $this->arrayToIni($value, $fullKey);
                } else {
                    $ini .= "[$fullKey]\n";
                    $ini .= $this->arrayToIni($value);
                    $ini .= "\n";
                }
            } else {
                if (is_bool($value)) {
                    $value = $value ? 'true' : 'false';
                } elseif (is_numeric($value)) {
                    $value = (string)$value;
                } else {
                    $value = '"' . addslashes($value) . '"';
                }
                $ini .= $fullKey . ' = ' . $value . "\n";
            }
        }
        
        return $ini;
    }
    
    public function backup($backupName = null) {
        $backupName = $backupName ?: 'backup_' . date('Y-m-d_H-i-s');
        $backupFile = $this->configDir . DIRECTORY_SEPARATOR . $backupName . '.json';
        
        $backupData = [
            'timestamp' => time(),
            'version' => '1.0',
            'config' => $this->configData
        ];
        
        $content = json_encode($backupData, JSON_PRETTY_PRINT);
        return file_put_contents($backupFile, $content) !== false;
    }
    
    public function restore($backupName) {
        $backupFile = $this->configDir . DIRECTORY_SEPARATOR . $backupName . '.json';
        
        if (!file_exists($backupFile)) {
            return false;
        }
        
        $content = file_get_contents($backupFile);
        $backupData = json_decode($content, true);
        
        if (isset($backupData['config'])) {
            $this->configData = $backupData['config'];
            return $this->saveConfig();
        }
        
        return false;
    }
