📚 Exam Preparation Guide

1 Chapter 1: PHP Basics - Key Points

  • PHP is server-side scripting language - code executes on server, browser sees HTML
  • Variables start with $ - case sensitive - $name != $Name
  • Data types: Integer, Float, String, Boolean, Array, Object, NULL
  • Comments: // (single), /* */ (multi), # (single)
  • echo vs print: echo has no return value, print has return value 1, echo is faster
  • Constants cannot be changed once defined - use define() function
  • GET: visible in URL, 2000 char limit, used for non-sensitive data, bookmarkable
  • POST: hidden in request body, no limit, used for passwords, more secure
  • Control structures: if-else, switch for conditional execution
  • Loops: for, while, do-while, foreach - break and continue control flow
  • Operators: Arithmetic (+,-,*,/,%,**), Comparison, Logical (&&,||,!), String (.)
  • Arrays: indexed (numeric), associative (string keys), multidimensional (nested)
  • Magic constants: __FILE__, __LINE__, __DIR__

2 Chapter 2: Functions & Strings - Key Points

  • Functions reduce code repetition and improve organization
  • Return statement exits function and returns value
  • Call by value: changes don't affect original variable
  • Call by reference: use & to modify original variable
  • Default parameters: function addition($a=1, $b=1)
  • Anonymous functions (closures): $add = function($a,$b){return $a+$b;}
  • Recursive functions call themselves - must have base case to avoid infinite recursion
  • strlen(), substr(), strpos(), str_replace() are common string functions
  • Regular expressions use delimiters /pattern/modifiers
  • preg_match() returns 1 or 0, preg_match_all() returns count
  • String comparison: strcmp(), str_word_count()
  • Case conversion: strtoupper(), strtolower(), ucfirst(), ucwords()
  • Pattern matching: [abc] (character class), [0-9] (digits), * (0+ times), + (1+ times)

3 Chapter 3: Arrays - Key Points

  • Arrays store multiple values in single variable
  • Indexed arrays: numeric keys starting from 0
  • Associative arrays: string keys => values
  • Multidimensional arrays: arrays within arrays
  • count() returns number of elements
  • sort(), rsort() modify original array - sort ascending/descending
  • Sorting maintains keys: asort(), arsort(), ksort(), krsort()
  • array_push() adds element(s) to end, array_pop() removes last
  • array_merge() combines arrays, array_slice() gets portion
  • in_array() checks if value exists, array_search() returns key of value
  • foreach loop: foreach($arr as $key=>$value) for iteration
  • array_map(), array_filter() for transformation and filtering
  • array_reduce() for aggregation operations
  • array_unique() removes duplicates, array_reverse() reverses order

4 Chapter 4: OOP - Key Points

  • OOP focuses on data and functions together, not just procedures
  • Class: blueprint, Object: instance of class
  • $this refers to current object instance
  • Access modifiers: public (everywhere), private (class only), protected (class + children)
  • Constructor: __construct() - automatically called on object creation
  • Destructor: __destruct() - called when object destroyed
  • Static: class-level, not instance level, accessed via ClassName::
  • Inheritance: child extends parent, reuses code
  • Method overriding: child redefines parent method
  • parent:: calls parent method, self:: accesses static members
  • Interfaces: define methods that class must implement
  • Abstract classes: cannot instantiate, define structure for children
  • Polymorphism: same method name, different implementations
  • instanceof: check if object is instance of class
  • Encapsulation: data hiding with private members + getters/setters

5 Chapter 5: Files & Directories - Key Points

  • fopen() opens file with mode: r(read), w(write), a(append), r+, w+, a+
  • fclose() closes file handle - important to free resources
  • fread() reads specified bytes, fgets() reads line, fgetc() reads single character
  • fwrite()/fputs() write to file
  • file_exists() checks if file exists, filesize() returns size in bytes
  • readfile() outputs file directly, file() reads entire file into array
  • file_put_contents() writes to file easily, file_get_contents() reads entire file
  • unlink() deletes file, copy() copies file, rename() renames file
  • opendir(), readdir(), closedir() for directory operations
  • scandir() returns array of directory contents
  • mkdir() creates directory, rmdir() removes empty directory
  • File upload: $_FILES array contains file info
  • move_uploaded_file() moves uploaded file to destination
  • Validate: file exists, size check, type check, image validation
  • Security: whitelist extensions, check MIME type, rename files, use temp directories

📘 Chapter 1: Introduction to PHP

1 Evolution of PHP

PHP stands for "PHP: Hypertext Preprocessor" and was developed by Rasmus Lerdorf in 1994. It has evolved through multiple versions:
PHP 1 (1995): First release as Personal Home Page
PHP 2 (1997): Major rewrite, renamed to Hypertext Preprocessor
PHP 3-5 (1998-2004): Added OOP, better performance
PHP 7 (2015): Significant performance improvements
PHP 8 (2020): Just-in-time compilation, named arguments

2 Features of PHP

PHP is a powerful server-side scripting language with numerous advantages:
  • ✓ Server-side scripting language executed on the server
  • ✓ Open source and free to use
  • ✓ 1000+ built-in functions available
  • ✓ Compatible with MySQL, PostgreSQL, and other databases
  • ✓ Runs on Windows, Linux, Unix, and macOS
  • ✓ Easy to learn syntax similar to C/C++

3 Variables & Data Types

Variables store data values in PHP. Variable names start with $ and are case-sensitive.
$name = "PHP"; // String
$age = 25; // Integer
$price = 19.99; // Float
<?php
$num = 20;
$name = "Hello";
$flag = true;

echo $num; // Output: 20
echo $name; // Output: Hello
echo $flag; // Output: 1 (true)
?>

🌍 Real-Life Application

Variables are used in e-commerce sites to store product prices, user information, and shopping cart data.

4 Operators

PHP supports various operators for arithmetic, comparison, logical, and string operations:
// Arithmetic Operators
$a = 10; $b = 3;
echo $a + $b; // 13 (Addition)
echo $a % $b; // 1 (Modulus)

// Comparison Operators
var_dump($a == $b); // false
var_dump($a > $b); // true

// Logical Operators
$x = true; $y = false;
var_dump($x && $y); // false (AND)

5 Control Structures

Control structures allow conditional execution and looping:
// if-else statement
if ($age >= 18) {
  echo "Adult";
} else {
  echo "Minor";
}

// for loop
for ($i = 1; $i <= 5; $i++) {
  echo $i . "<br>";
}

// foreach loop
$colors = ["Red", "Green", "Blue"];
foreach ($colors as $color) {
  echo $color;
}

🌍 Real-Life Application

Control structures are used to validate user input, process form submissions, and loop through database records.

6 Loop Statements

Different types of loops for iteration:
// while loop
$i = 1;
while ($i <= 5) {
  echo $i . "<br>";
  $i++;
}

// do-while loop (executes at least once)
$x = 1;
do {
  echo $x . "<br>";
  $x++;
} while ($x <= 5);

// switch statement
$day = 3;
switch ($day) {
  case 1: echo "Monday"; break;
  case 2: echo "Tuesday"; break;
  case 3: echo "Wednesday"; break;
  default: echo "Other";
}

7 Jump Statements

Break and continue control loop flow:
// break statement - exits loop
for ($i = 1; $i <= 10; $i++) {
  if ($i == 5) break;
  echo $i . "<br>";
}

// continue statement - skip to next iteration
for ($i = 1; $i <= 10; $i++) {
  if ($i % 2 == 0) continue;
  echo $i . "<br>"; // prints odd numbers
}

8 GET and POST Methods

Methods to collect form data from users:
// GET method (visible in URL)
<form method="get" action="process.php">
  <input type="text" name="username">
  <input type="submit">
</form>

// Access in PHP
echo $_GET["username"]; // visible in URL

// POST method (hidden in request body)
<form method="post" action="process.php">
  <input type="password" name="password">
  <input type="submit">
</form>

// Access in PHP
echo $_POST["password"]; // not visible in URL
GET: Visible, limited 2000 chars, bookmarkable
POST: Hidden, no limit, not bookmarkable, more secure

📗 Chapter 2: Functions & Strings

1 User-Defined Functions

Functions are reusable blocks of code that perform specific tasks. They help organize code and improve maintainability.
// Function definition
function greet($name) {
  return "Hello, " . $name;
}

// Function call
echo greet("Alice"); // Output: Hello, Alice

2 Function Parameters

Functions can accept parameters to process different data. Parameters can have default values.
// Non-parameterized function
function display() {
  echo "Hello World!!!";
}

// Parameterized function with default values
function addition($a = 1, $b = 1) {
  return $a + $b;
}

echo addition(10, 20); // Output: 30
echo addition(10); // Output: 11

🌍 Real-Life Application

Parameterized functions are used in APIs to send request data, in calculators to compute results, and in email systems to format messages.

3 Anonymous Functions

Anonymous functions (closures) don't have names and can be assigned to variables for flexible code execution.
$add = function ($a, $b) {
  return $a + $b;
};

echo $add(5, 10); // Output: 15

4 Recursive Functions

Recursive functions call themselves to solve problems by breaking them into smaller subproblems.
function factorial($n) {
  if ($n <= 1) return 1;
  return $n * factorial($n - 1);
}

echo factorial(5); // Output: 120

5 String Functions

PHP provides powerful string manipulation functions for text processing:
$str = "Hello World";

strlen($str); // 11 - String length
strtoupper($str); // HELLO WORLD
strtolower($str); // hello world
substr($str, 0, 5); // Hello
str_replace("World", "PHP", $str); // Hello PHP
strpos($str, "World"); // 6

🌍 Real-Life Application

String functions are used in search engines (substr), email validation (strpos), and text transformations in content management systems.

6 Regular Expressions

Regular expressions provide powerful pattern matching and text manipulation capabilities. Syntax: /pattern/modifiers where delimiters (/) enclose pattern and modifiers (i, m, g) modify behavior.
$pattern = "/World/i"; // Case-insensitive
$str = "Hello World";

// preg_match() - returns 1 if found, 0 if not
if (preg_match($pattern, $str)) {
  echo "Match found!";
}

// preg_match_all() - count all matches
$text = "The rain in SPAIN falls on plains";
echo preg_match_all("/ain/i", $text); // Output: 4

// Replace matches
$result = preg_replace("/World/", "PHP", $str);
echo $result; // Hello PHP

// preg_split() - split by pattern
$date = "10-08-2025";
$parts = preg_split("/-/", $date);
// Result: Array ( [0] => 10 [1] => 08 [2] => 2025 )
[abc]: Find one char from a, b, c
[0-9]: Find one digit 0-9
[^abc]: Find char NOT a, b, c
i modifier: Case-insensitive search

7 Built-in String Functions

PHP provides extensive string manipulation functions:
// Length and character operations
strlen("Hello"); // 5
str_word_count("Hello World PHP"); // 3
strrev("Hello"); // "olleH"

// Case conversion
strtoupper("hello"); // HELLO
strtolower("HELLO"); // hello
ucfirst("hello"); // Hello
ucwords("hello world"); // Hello World

// Search and replace
strpos("Hello World", "World"); // 6
str_replace("World", "PHP", "Hello World");
substr("Hello World", 0, 5); // Hello

// Trimming whitespace
trim(" Hello "); // Hello
ltrim(" Hello"); // Hello
rtrim("Hello "); // Hello

// Comparison
strcmp("abc", "abc"); // 0 (equal)
strcmp("abc", "xyz"); // -1 (first less)

// Special functions
str_repeat("ab", 3); // ababab
str_pad("5", 3, "0", STR_PAD_LEFT); // 005
implode(",", ["a", "b"]); // a,b
explode(",", "a,b,c"); // Array

🌍 Real-Life Applications

String functions used in: email validation, password strength checking, username formatting, text search engines, content filtering, and data formatting for display.

📙 Chapter 3: Working with Arrays

1 Indexed Arrays

Indexed arrays store values in linear order with numeric indices starting from 0.
$courses = array("OS", "Java", "PHP", "IOT");

// Access elements
echo $courses[0]; // OS
echo $courses[2]; // PHP

// Iterate through array
foreach ($courses as $course) {
  echo $course . "<br>";
}

2 Associative Arrays

Associative arrays use string keys to establish strong associations between keys and values.
$student = array(
  "name" => "Amit",
  "roll" => 101,
  "percentage" => 85.5
);

echo $student["name"]; // Amit
echo $student["percentage"]; // 85.5

3 Multidimensional Arrays

Multidimensional arrays contain arrays within arrays, useful for representing complex data structures.
$students = array(
  array("Amit", 21, 90),
  array("Annad", 22, 85),
  array("Rutuja", 21, 92)
);

echo $students[0][0]; // Amit
echo $students[1][2]; // 85

🌍 Real-Life Application

Multidimensional arrays are used in database queries to store multiple records, in spreadsheets, and in game boards.

4 Array Functions

PHP provides powerful array manipulation functions:
$arr = array(3, 1, 4, 1, 5, 9);

count($arr); // 6
sort($arr); // Sort ascending
rsort($arr); // Sort descending
array_merge($arr, $arr2); // Combine arrays
array_push($arr, 10); // Add element
array_pop($arr); // Remove last element
array_sum($arr); // Sum of elements

5 Sorting Arrays

Various sorting methods are available for different array types:
// Indexed arrays
sort($arr); // Ascending
rsort($arr); // Descending

// Associative arrays
asort($arr); // By value, ascending
arsort($arr); // By value, descending
ksort($arr); // By key, ascending
krsort($arr); // By key, descending

6 Advanced Array Functions

More powerful array manipulation functions:
// Array manipulation
array_push($arr, "value"); // Add to end
array_pop($arr); // Remove last
array_shift($arr); // Remove first
array_unshift($arr, "value"); // Add to start

// Array searching
in_array("PHP", $arr); // Check if exists
array_search("PHP", $arr); // Get key of value
array_key_exists("name", $arr); // Check key exists

// Array operations
array_merge($arr1, $arr2); // Combine arrays
array_slice($arr, 1, 2); // Get portion
array_splice($arr, 1, 2, ["new"]); // Replace portion
array_reverse($arr); // Reverse order
array_unique($arr); // Remove duplicates

// Mathematical operations
array_sum($arr); // Sum elements
array_product($arr); // Multiply elements
count($arr); // Count elements

// Array comparison
array_diff($arr1, $arr2); // Difference
array_intersect($arr1, $arr2); // Common values

// Advanced operations
array_chunk($arr, 2); // Split into chunks
array_combine($keys, $values); // Combine two arrays
array_flip($arr); // Swap keys/values
extract($arr); // Import as variables

🌍 Real-Life Applications

Used in shopping carts (array_push/pop), pagination (array_slice), data filtering (array_diff), database result processing (array_combine), and configuration management (extract).

📕 Chapter 4: Object-Oriented Programming

1 Classes & Objects

Classes are user-defined data types containing data members and methods. Objects are instances of classes.
class Book {
  public $title;
  public $author;
  
  function setDetails($t, $a) {
    $this->title = $t;
    $this->author = $a;
  }
}

$book = new Book();
$book->setDetails("PHP Basics", "John Doe");

2 Constructors & Destructors

Constructors initialize object properties automatically, while destructors clean up when objects are destroyed.
class Student {
  public $name;
  
  function __construct($n) {
    $this->name = $n;
  }
  
  function __destruct() {
    echo "Destroying student: " . $this->name;
  }
}

$s = new Student("Alice");

3 Access Modifiers

Access modifiers control visibility of class properties and methods:
Public: Accessible everywhere (default)
Private: Accessible only within the class
Protected: Accessible in the class and derived classes

4 Inheritance

Inheritance allows a child class to inherit properties and methods from a parent class using the 'extends' keyword.
class Animal {
  public function eat() {
    echo "Eating...";
  }
}

class Dog extends Animal {
  public function bark() {
    echo "Woof!";
  }
}

$dog = new Dog();
$dog->eat(); // Inherited method
$dog->bark(); // Own method

🌍 Real-Life Application

Inheritance is used in frameworks like Laravel to create base controllers and models that are extended by specific classes.

5 Polymorphism

Polymorphism allows the same method to be used for different objects, often through method overriding.
class Shape {
  public function area() {
    return 0;
  }
}

class Circle extends Shape {
  private $radius;
  
  public function __construct($r) {
    $this->radius = $r;
  }
  
  public function area() {
    return 3.14 * $this->radius * $this->radius;
  }
}

6 Static Members

Static properties and methods belong to the class, not to objects. They're accessed using the class name.
class Counter {
  public static $count = 0;
  
  public static function increment() {
    self::$count++;
  }
}

Counter::increment();
echo Counter::$count; // 1

7 Interfaces

Interfaces define contracts that classes must implement, ensuring consistency across implementations.
interface Drawable {
  public function draw();
  public function getArea();
}

class Circle implements Drawable {
  private $radius;
  
  public function draw() {
    echo "Drawing circle...";
  }
  
  public function getArea() {
    return 3.14 * $this->radius * $this->radius;
  }
}

// Single class can implement multiple interfaces
class Square implements Drawable, Printable { ... }

8 Abstract Classes

Abstract classes cannot be instantiated but define base implementations for subclasses:
abstract class Shape {
  protected $name;
  
  // Abstract method - must be implemented
  abstract public function calculateArea();
  
  // Concrete method - can be inherited
  public function getName() {
    return $this->name;
  }
}

class Rectangle extends Shape {
  private $width, $height;
  
  public function calculateArea() {
    return $this->width * $this->height;
  }
}

// $shape = new Shape(); // ERROR: Cannot instantiate
$rect = new Rectangle(); // OK

9 Advanced OOP Concepts

Additional OOP features for robust design:
// Type Hints
function processUser(User $user): string {
  return $user->getName();
}

// Visibility in inheritance
class Parent {
  public $pub = "accessible everywhere";
  protected $prot = "accessible in child";
  private $priv = "not accessible";
}

// Function Overriding
class Parent {
  public function greet() {
    echo "Hello from parent";
  }
}

class Child extends Parent {
  public function greet() { // Override
    parent::greet(); // Call parent method
    echo "Hello from child";
  }
}

// instanceof operator
$obj = new Child();
if ($obj instanceof Child) {
  echo "Yes, instance of Child";
}
if ($obj instanceof Parent) {
  echo "Also instance of Parent";
}

10 Final Keyword

Prevent overriding or inheritance:
// Prevent class inheritance
final class Config {
  // Cannot be extended
}

// Prevent method overriding
class Database {
  final public function connect() {
    // Critical method, cannot override
  }
}

// child class cannot override
class MySQL extends Database {
  // public function connect() { } // ERROR
}

📓 Chapter 5: Files & Directories

1 File Operations

PHP provides functions to open, read, write, and close files. File handling is essential for data persistence.
// Open file
$file = fopen("test.txt", "r"); // r: read, w: write, a: append

// Read file
$content = fread($file, filesize("test.txt"));
echo $content;

// Close file
fclose($file);

2 Reading Files

Multiple methods are available to read file contents with different use cases.
// Method 1: fread() - Read entire file
$content = fread($file, filesize("test.txt"));

// Method 2: fgets() - Read line by line
while (!feof($file)) {
  echo fgets($file) . "<br>";
}

// Method 3: readfile() - Output file directly
readfile("test.txt");

// Method 4: file() - Read into array
$lines = file("test.txt");

3 Writing to Files

Writing data to files is crucial for storing application data persistently.
// Open file in write mode
$file = fopen("test.txt", "w");

// Write data
fwrite($file, "Hello World\n");
fwrite($file, "PHP File Operations");

// Close file
fclose($file);

🌍 Real-Life Application

File writing is used in logging systems, configuration files, CSV exports, and caching mechanisms.

4 File Utilities

Useful functions for file management:
file_exists("test.txt"); // Check if file exists
filesize("test.txt"); // Get file size in bytes
is_file("test.txt"); // Check if it's a file
is_dir("folder"); // Check if it's a directory
rename("old.txt", "new.txt"); // Rename file
unlink("test.txt"); // Delete file
copy("src.txt", "dst.txt"); // Copy file

5 Directory Operations

Functions for working with directories and listing contents:
// Open directory
$dir = opendir("./uploads");

// Read directory contents
while ($file = readdir($dir)) {
  echo $file . "<br>";
}

// Close directory
closedir($dir);

// Modern approach - scandir()
$files = scandir("./uploads");
print_r($files);

6 File Operations Detailed

Comprehensive file handling operations:
// File modes for fopen()
$file = fopen("data.txt", "r"); // Read only

8 File Upload with Validation

Secure file upload handling with comprehensive validation:
// HTML Form
<form enctype="multipart/form-data" method="post">
  <input type="file" name="fileToUpload">
  <input type="submit">
</form>

// PHP Processing
$target_dir = "uploads/";
$target_file = $target_dir . basename($_FILES["fileToUpload"]["name"]);
$uploadOk = 1;
$fileType = strtolower(pathinfo($target_file, PATHINFO_EXTENSION));

// Check if file already exists
if (file_exists($target_file)) {
  echo "File already exists";
  $uploadOk = 0;
}

// Check file size
if ($_FILES["fileToUpload"]["size"] > 500000) {
  echo "File too large";
  $uploadOk = 0;
}

// Allow certain formats
$allowed = ["jpg", "jpeg", "png", "gif"];
if (!in_array($fileType, $allowed)) {
  echo "Invalid file type";
  $uploadOk = 0;
}

// Upload if valid
if ($uploadOk && move_uploaded_file(
  $_FILES["fileToUpload"]["tmp_name"],
  $target_file)) {
  echo "File uploaded successfully";
}
