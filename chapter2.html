PHP Functions

A function is a block of statements that can be used repeatedly in a program. Functions help organize code, reduce repetition, and make programs more modular and maintainable.

Benefits of Using Functions:

  • • Code Reusability: Write once, use multiple times
  • • Modularity: Break complex problems into smaller, manageable pieces
  • • Maintainability: Easier to update and debug code
  • • Readability: Makes code more organized and understandable

PHP has over 1000+ built-in functions that can be called directly, and you can also create your own custom functions.

Built-in Functions

PHP provides a rich set of built-in functions that perform common tasks. These functions are ready to use without any additional setup.

String Functions

  • • strlen() - Get string length
  • • strpos() - Find position of substring
  • • substr() - Extract part of string
  • • str_replace() - Replace text in string
  • • strtolower() - Convert to lowercase
  • • strtoupper() - Convert to uppercase

Array Functions

  • • count() - Count array elements
  • • array_push() - Add elements to array
  • • array_pop() - Remove last element
  • • array_merge() - Merge arrays
  • • sort() - Sort array
  • • in_array() - Check if value exists

Date/Time Functions

  • • date() - Format date and time
  • • time() - Get current timestamp
  • • strtotime() - Convert string to timestamp
  • • mktime() - Create timestamp

Mathematical Functions

  • • abs() - Absolute value
  • • round() - Round numbers
  • • rand() - Generate random number
  • • max() - Find maximum value
  • • min() - Find minimum value
Built-in Functions Examples
<?php
// String functions
$name = "PHP Programming";
echo strlen($name);           // Output: 16
echo strpos($name, "Prog");   // Output: 4
echo strtoupper($name);       // Output: PHP PROGRAMMING

// Array functions
$numbers = array(5, 2, 8, 1, 9);
echo count($numbers);         // Output: 5
sort($numbers);
print_r($numbers);            // Output: Array ( [0] => 1 [1] => 2 [2] => 5 [3] => 8 [4] => 9 )

// Date functions
echo date("Y-m-d H:i:s");     // Output: Current date and time
echo time();                  // Output: Current timestamp

// Mathematical functions
echo abs(-42);                // Output: 42
echo round(3.14159, 2);       // Output: 3.14
echo rand(1, 100);            // Output: Random number between 1 and 100
?>

User-defined Functions

You can create your own functions to perform specific tasks. A user-defined function declaration starts with the word "function".

Function Naming Rules:

  • • Must start with a letter or underscore
  • • Function names are NOT case-sensitive
  • • Cannot use reserved keywords
  • • Should be descriptive and meaningful
User-defined Function Syntax
<?php
// Basic function syntax
function functionName() {
    // Function body
    // Code to be executed
}

// Function with parameters
function functionName($parameter1, $parameter2) {
    // Function body
    return $result;
}

// Two steps to use functions:
// 1. Function definition
// 2. Function call

// Example 1: Simple function
greetUser();

greetUser() {
    echo "Hello, Welcome to PHP!";
}

// Example 2: Function with parameters
function addNumbers($a, $b) {
    $sum = $a + $b;
    return $sum;
}

$result = addNumbers(10, 20);
echo "The sum is: $result";  // Output: The sum is: 30
?>

Function Parameters

Functions can accept parameters (also known as arguments) to make them more flexible and reusable.

Non-parameterized Functions

Functions that don't accept any parameters and perform fixed operations.

Parameterized Functions

Functions that accept parameters to make them more flexible and reusable.

Function Parameter Examples
<?php
// Non-parameterized function
function displayWelcome() {
    echo "Hello World!!!";
}

displayWelcome();  // Output: Hello World!!!

// Parameterized function
function display($message) {
    echo $message;
}

display("Welcome to PHP!");  // Output: Welcome to PHP!
display("Learning functions");  // Output: Learning functions

// Function with multiple parameters
function calculate($num1, $num2, $operation) {
    switch($operation) {
        case 'add':
            return $num1 + $num2;
        case 'subtract':
            return $num1 - $num2;
        case 'multiply':
            return $num1 * $num2;
        case 'divide':
            return $num2 != 0 ? $num1 / $num2 : "Cannot divide by zero";
        default:
            return "Invalid operation";
    }
}

echo calculate(10, 5, 'add');        // Output: 15
echo calculate(10, 5, 'multiply');   // Output: 50
echo calculate(10, 0, 'divide');     // Output: Cannot divide by zero
?>

Parameter Types:

  • • Required Parameters: Must be provided when calling the function
  • • Optional Parameters: Have default values and are not required
  • • Variable Arguments: Can accept unlimited number of arguments

String Functions

PHP provides powerful string manipulation functions. Here are some of the most commonly used string functions:

Function Description Example
strlen() Returns the length of a string strlen("Hello") → 5
strpos() Finds the position of the first occurrence of a substring strpos("Hello World", "World") → 6
str_replace() Replaces all occurrences of a search string str_replace("World", "PHP", "Hello World") → "Hello PHP"
strtolower() Converts string to lowercase strtolower("HELLO") → "hello"
strtoupper() Converts string to uppercase strtoupper("hello") → "HELLO"
substr() Returns part of a string substr("Hello World", 0, 5) → "Hello"
trim() Removes whitespace from both ends trim(" Hello ") → "Hello"
explode() Splits a string into an array explode(" ", "Hello World") → ["Hello", "World"]
String Functions Examples
<?php
// String length
$text = "PHP Programming";
echo "Length: " . strlen($text) . "\n";  // Output: Length: 16

// String position
$position = strpos($text, "Prog");
echo "Position of 'Prog': $position\n";  // Output: Position of 'Prog': 4

// String replacement
$newText = str_replace("Programming", "Development", $text);
echo "Replaced: $newText\n";  // Output: Replaced: PHP Development

// Case conversion
echo "Uppercase: " . strtoupper($text) . "\n";  // Output: Uppercase: PHP PROGRAMMING
echo "Lowercase: " . strtolower($text) . "\n";  // Output: Lowercase: php programming

// String extraction
$substring = substr($text, 4, 11);
echo "Substring: $substring\n";  // Output: Substring: Programming

// String splitting
$words = explode(" ", "Hello World from PHP");
print_r($words);
// Output: Array ( [0] => Hello [1] => World [2] => from [3] => PHP )

// String trimming
$spaced = "  Extra spaces  ";
echo "Original: '$spaced'\n";  // Output: Original: '  Extra spaces  '
echo "Trimmed: '" . trim($spaced) . "'\n";  // Output: Trimmed: 'Extra spaces'
?>

Practical Code Examples

Example 1: String Manipulation Function

Custom String Processor
<?php
function processString($input) {
    // Remove extra spaces
    $cleaned = trim($input);
    
    // Convert to proper case
    $properCase = ucwords(strtolower($cleaned));
    
    // Get word count
    $wordCount = str_word_count($properCase);
    
    // Get character count (excluding spaces)
    $charCount = strlen(str_replace(' ', '', $properCase));
    
    // Return processed information
    return array(
        'original' => $input,
        'processed' => $properCase,
        'wordCount' => $wordCount,
        'charCount' => $charCount,
        'length' => strlen($properCase)
    );
}

// Test the function
$testString = "  hello world from php  ";
$result = processString($testString);

echo "Original: '" . $result['original'] . "'\n";
echo "Processed: '" . $result['processed'] . "'\n";
echo "Word Count: " . $result['wordCount'] . "\n";
echo "Character Count: " . $result['charCount'] . "\n";
echo "Total Length: " . $result['length'] . "\n";
?>

Example 2: Calculator Function

Advanced Calculator
<?php
function calculator($num1, $num2, $operation = 'add') {
    // Validate inputs
    if (!is_numeric($num1) || !is_numeric($num2)) {
        return "Error: Both inputs must be numbers";
    }
    
    // Perform calculation based on operation
    switch(strtolower($operation)) {
        case 'add':
        case '+':
            $result = $num1 + $num2;
            $symbol = '+';
            break;
        case 'subtract':
        case '-':
            $result = $num1 - $num2;
            $symbol = '-';
            break;
        case 'multiply':
        case '*':
            $result = $num1 * $num2;
            $symbol = '*';
            break;
        case 'divide':
        case '/':
            if ($num2 == 0) {
                return "Error: Cannot divide by zero";
            }
            $result = $num1 / $num2;
            $symbol = '/';
            break;
        case 'power':
        case '**':
            $result = pow($num1, $num2);
            $symbol = '**';
            break;
        default:
            return "Error: Invalid operation. Use add, subtract, multiply, divide, or power";
    }
    
    return array(
        'expression' => "$num1 $symbol $num2",
        'result' => $result,
        'operation' => $operation
    );
}

// Test the calculator
$tests = array(
    array(10, 5, 'add'),
    array(20, 3, 'multiply'),
    array(100, 0, 'divide'),
    array(2, 8, 'power')
);

foreach ($tests as $test) {
    $result = calculator($test[0], $test[1], $test[2]);
    if (is_array($result)) {
        echo $result['expression'] . " = " . $result['result'] . "\n";
    } else {
        echo $result . "\n";
    }
}
?>
